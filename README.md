# K7 ESPORTS — Official Website (v2)

Профессиональный минималистичный сайт киберспортивной команды K7 ESPORTS по Counter-Strike 2 в стиле HLTV.

## Что реализовано

- Современный тёмный минималистичный дизайн
- Логотип **K7** (белый текст, без жёлтой эмблемы)
- Регион команды (редактируемый)
- **5 карточек игроков в одном ряду** на ПК и на телефоне (320–430 px)
- Редактируемая статистика команды (Rating 3.0, Winrate, Entrying, Utility)
- 4 цветовые темы: Black/Red, White/Red, Black/Yellow, Black/Blue
- Русский / Английский языки
- Полноценная админ-панель (скрытый вход удержанием шестерёнки)
- **Серверная авторизация** — пароль проверяется на сервере, JWT-сессии
- Данные общие для всех посетителей (хранятся на сервере)
- Матчи, новости, хайлайты, социальные ссылки
- Адаптивная вёрстка без горизонтальной прокрутки страницы
- Анимации появления секций (с учётом prefers-reduced-motion)

## Быстрый старт локально

```bash
npm install
cp .env.example .env
# отредактируйте .env при необходимости
npm start
```

Откройте http://localhost:3000

## Админ-панель

1. На сайте нажмите и **удерживайте** иконку шестерёнки ~0.8 сек (или дважды кликните).
2. Введите пароль: `alskdjfhG10` (или тот, что задан в `ADMIN_PASSWORD`).
3. Управляйте составом, статистикой, матчами, новостями, темами и ссылками.
4. Все изменения сохраняются на сервере и видны всем посетителям.

**Важно:** пароль никогда не хранится в HTML/JS клиентского кода.

## Публикация на Render (инструкция с телефона)

### 1. GitHub

1. Создайте новый репозиторий на GitHub (например `k7-esports`).
2. Загрузите все файлы из этой папки (можно через приложение GitHub или Working Copy / a-Shell + git).
3. Не загружайте файл `.env` и папку `node_modules` / `data`.

### 2. Render

1. Зайдите на [render.com](https://render.com) → New → **Web Service**.
2. Подключите GitHub-репозиторий.
3. Настройки:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
4. **Environment Variables** (обязательно добавить):
   - `ADMIN_PASSWORD` = `alskdjfhG10` (или свой надёжный пароль)
   - `JWT_SECRET` = длинная случайная строка (минимум 32 символа)
5. Создайте сервис и дождитесь деплоя.

После деплоя сайт будет доступен по адресу вида `https://k7-esports-xxxx.onrender.com`.

### Важно про данные на бесплатном тарифе Render

Файловая система бесплатного Web Service **эфемерная** — при перезапуске/сне данные из папки `data/` и `uploads/` могут сброситься.

Для постоянной работы:

**Вариант A (рекомендуется):** подключить **Supabase** (бесплатный PostgreSQL + Storage).  
Схема таблиц лежит в папке `supabase/`. После создания проекта Supabase нужно будет доработать `server.js` под Postgres (или использовать Supabase JS client).

**Вариант B:** подключить платный Render Disk или внешнюю БД.
